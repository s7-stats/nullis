# Getting started with nullis

## Introduction

[nullis](https://github.com/s7-stats/nullis) is an extension of
[statim](https://s7-stats.github.io/statim/) dedicated for nonparametric
statistics

## Current

Here are the collection of Hypothesis tests under nonparametric
statistics implemented in [nullis](https://github.com/s7-stats/nullis):

1.  Mood’s median test
    ([`MEDIAN_TEST()`](https://s7-stats.github.io/nullis/reference/MEDIAN_TEST.md))
2.  Friedman’s Rank Sum test
    ([`FRIEDMAN_TEST()`](https://s7-stats.github.io/nullis/reference/FRIEDMAN_TEST.md))
3.  Kruskal-Wallis H test
    ([`KW_TEST()`](https://s7-stats.github.io/nullis/reference/KW_TEST.md))
4.  Jonckheere-Terpstra test
    ([`JT_TEST()`](https://s7-stats.github.io/nullis/reference/JT_TEST.md))
5.  Cochran’s Q test
    ([`COCHRAN_QTEST()`](https://s7-stats.github.io/nullis/reference/COCHRAN_QTEST.md))
