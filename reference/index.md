# Package index

## H-test functions

Main functions for nonparametric H-tests

- [`FRIEDMAN_TEST()`](https://s7-stats.github.io/nullis/reference/FRIEDMAN_TEST.md)
  : Friedman Rank Sum Test
- [`KW_TEST()`](https://s7-stats.github.io/nullis/reference/KW_TEST.md)
  : Kruskal-Wallis rank sum test

## Base `<class_stat_infer>` classes

Extension of `class_stat_infer` S7 class from
[statim](https://github.com/s7-stats/statim)

- [`class_kw_test`](https://s7-stats.github.io/nullis/reference/class_kw_test.md)
  : Structured result container for Kruskal-Wallis test

## `{nullis}` own `<var_id>` mappers

Extension of `<var_id>` mappers in this package

- [`x_by_b()`](https://s7-stats.github.io/nullis/reference/x_by_b.md) :
  Compare a variable by group given block
